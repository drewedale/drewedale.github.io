MATLAB · Digital signal processing · Experimental synthesis

Concatenative timbre synthesis

A prototype that segments source recordings into grains, compares Bark-spectrum and harmonic-ratio features with a target, then reassembles selected grains with overlap-add. The repository includes the original coursework and a documented revision; the revision has been reviewed but not run in MATLAB.
