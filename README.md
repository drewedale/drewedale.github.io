# drewedale.github.io

Personal portfolio for Andrew Dale / Andra, built as a lightweight static site for GitHub Pages.

## Files

- `index.html` — page content and links
- `style.css` — layout, colors, responsive design, and motion
- `script.js` — mobile menu and small visual enhancements
- `assets/andra-logo.png` — Andra logo

## Updating the site

Most text and links can be changed directly in `index.html`. Keep project images in `assets/` and use short, lowercase filenames without spaces.
