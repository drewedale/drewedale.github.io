# The Kinected DJ

Open `kinectDJ.maxpat` in Max with the companion `.maxpat` files from this directory alongside it. The patch maps tracked body motion from an Xbox Kinect, transmitted over OSC, to effects in a DJ performance.

The original setup used KinectV2-OSC, Rekordbox, a DDJ-400, configured audio routing, and performer-specific calibration. The [paper](https://drewedale.github.io/assets/kinected-dj-paper.pdf) and [performance video](https://drewedale.github.io/audio-coding.html#kinected-dj) explain the instrument. This is a historical source selection, not a tested one-click build; some effect modules require external packages or have external origins and unverified licensing.
