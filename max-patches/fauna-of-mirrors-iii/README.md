# Fauna of Mirrors III

Open `MaxPatch.maxpat` in Max. It plays stereo tape to outputs 1–2 and a synchronized click track to performer headphone outputs 3–7. The patch was created for a FUSE Ensemble performance.

The `Tape.wav` and `Metro_Stereo.wav` recordings are not included. Supply the original files, relink the two `playlist~` objects to local copies, and configure a multichannel audio interface. Source file references have been made relative for portability. This patch has not been tested against the original performance rig. [Portfolio entry and performance](https://drewedale.github.io/audio-coding.html#fauna-of-mirrors-iii).
