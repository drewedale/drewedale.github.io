# MIDI synthesizer

Open `Drew_Dale_MIDI_Synthesizer.maxpat` in Max, enable DSP, and play notes from a connected MIDI device. The patch offers waveform selection, timbre controls, an ADSR envelope, portamento, vibrato, tremolo, and chord intervals. Its subpatchers and generated wave tables are embedded in the file.

This is an audio programming assignment source patch. It has been inspected statically but not performance-tested for the portfolio. [Portfolio entry](https://drewedale.github.io/audio-coding.html#midi-synthesizer).
